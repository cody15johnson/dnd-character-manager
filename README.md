# D&D 5e Character Manager

A standalone, browser-based D&D 5e character management application.

## Current version
**v1.5.0** — the current application is served from `index.html`.

## Run locally
Open `index.html` in a modern browser. The application is a self-contained HTML file; no build step is required.

## Repository layout
- `index.html` — current v1.5.0 application.
- `release-notes/` — versioned release notes.
- `tests/` — test reports and regression test script.
- `history/versions/` — previous application snapshot(s).

## Project boundaries
This repository is for the Character Manager. The Dungeon Master Manager remains in its own repository. Cross-app regression materials, where included, are test documentation only. Shared integration-contract documents are not copied here.

## Privacy and publishing
This repository is private. No GitHub Pages deployment has been configured by this upload.
