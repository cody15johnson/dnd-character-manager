# D&D Character Manager v1.4.0 — Release Notes

## Character note linking and suggestions

- **Explicit note links:** Character notes can link to other notes belonging to the same character.
- **Two-way relationships:** Adding a link records the relationship on both notes. Removing a link removes it from both sides.
- **Related-note previews:** Expand a linked note inside the editor to read its content without leaving the current note.
- **Reviewable suggestions:** The editor suggests possible links when notes share tags or a note title is mentioned in the current note's title/body. Suggestions never create links automatically; the user chooses **Link**.
- **Safe reference cleanup:** Deleting a note removes its references from other notes. Imported notes have invalid/self-references filtered, and valid links are repaired into two-way relationships.
- **Backward compatibility:** Existing character notes without a `links` field continue to load. Links are stored inside the character data and therefore travel with character and roster JSON exports/imports.
- **Version:** Character Manager application version is now 1.4.0.
