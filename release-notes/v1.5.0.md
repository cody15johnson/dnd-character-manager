# D&D 5e Character Manager v1.5.0 — Release Notes

## Knowledge discovery and connections

### Clickable tag exploration
- Tag chips on each note can be tapped to filter the note list.
- Existing tag filters remain available at the top of the Notes tab, including multi-tag filtering and clear filters.
- Tag counts remain visible so commonly used tags are easy to discover.

### Unified Notes / Connections browser
- Added a view switch between **Browse notes** and **Connections**.
- The Connections view lists notes with their confirmed linked notes and related notes discovered through shared tags.
- Confirmed links and tag-based relationships are labeled separately; shared tags never create a link automatically.
- Linked notes can be opened directly from the Connections view.

### Clearer note cards
- Note cards show clickable tag chips and direct links to confirmed related notes.
- Opening/editing a note continues to use the existing linked-note previews and reviewed link suggestions.

## Compatibility and data
- No new storage format is required; links and tags remain within each character's note records.
- Character JSON export/import continues to carry note links.
- Existing character records and notes remain compatible.

## Validation
- JavaScript syntax check passed with `node --check`.
- Playwright + system Chromium targeted browser tests: **7/7 passed**.
- Tests covered tag visibility, bidirectional link persistence, the Connections view, shared-tag discovery, opening notes from both views, and uncaught browser errors.
- Browser tests used a localStorage shim and did not test native file picker behavior or persistence in a real user browser profile.
